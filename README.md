# PracticaGithubCIFOG

Repositori utilitzat per al taller d'introducció a Git i GitHub.

## Exercicis

1. Clonar el repositori
2. Afegir el vostre fitxer a `students/`
3. Fer commit i push
4. Actualitzar els canvis dels companys (pull)
5. Resoldre un merge conflict
6. Crear una pull request

## Normes

- Cada alumne crea un fitxer dins `students/`
- El nom del fitxer ha de ser el vostre nom

Exemple:

students/martamenac.txt
